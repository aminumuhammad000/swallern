# Swallern Brand Package

Status: proposed production baseline pending founder visual approval.

Primary concept:
- Stylized S discovery mark + Swallern wordmark
- Plus Jakarta Sans
- Indigo/blue/cyan/purple gradient
- Yellow used sparingly for curiosity/highlight moments
- No dominant green brand direction

Files:
- swallern-brand-guideline-board.png — generated visual reference board
- swallern-logo.svg — light-background logo
- swallern-logo-dark.svg — dark-background logo
- swallern-icon.svg — app/favicon/social icon source

Core colors:
- Indigo #6366F1
- Blue #3B82F6
- Cyan #06B6D4
- Purple #A855F7
- Yellow #FACC15
- Dark #0F172A
- Slate #334155
- Gray #64748B
- Light #E2E8F0
- White #FFFFFF

Do not stretch, recolor arbitrarily, add effects, or place the mark on visually noisy backgrounds.
