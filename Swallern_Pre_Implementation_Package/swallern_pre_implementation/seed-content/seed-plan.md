# Swallern Seed Content Plan

Start with 30–100 carefully reviewed topics, not thousands of autogenerated pages.

Suggested initial category distribution:
- Science
- Technology
- History
- Space
- Nature
- Mathematics
- Psychology
- Economics
- Society
- Culture

Each seed topic should include:
- title
- summary
- quick answer
- key concepts
- explanation
- 2+ appropriate sources
- 4–8 related topics
- optional 5-question quiz
- optional short lesson

The seed set should intentionally test:
- simple topics
- complex topics
- question-shaped searches
- trending topics
- evergreen topics
- topics with rich media
- topics with source disagreement
