# Swallern Design System v1

## Visual principles
1. Curious, intelligent, playful, trustworthy, modern, warm, clear.
2. Whitespace and hierarchy before decoration.
3. Rounded components, but avoid childish/bubbly excess.
4. Indigo/blue is the trust/knowledge base; yellow is a highlight, not the primary field color.
5. Motion must explain, guide, or reward—not distract.

## Typography
- Headings/UI: Plus Jakarta Sans, 700/600/500.
- Body: Inter, 400/500.
- Minimum normal body size: 16px.
- Line-height target: 1.5–1.7 for body copy.

## Components
Header, SearchBar, TopicCard, TopicHero, SourceList, Citation, MediaBlock, LessonSection,
QuizQuestion, ProgressBar, SaveButton, RelatedTopicCard, Badge, Toast, Modal, Skeleton,
EmptyState, ErrorState, Footer.

## Accessibility
- Target WCAG 2.2 AA.
- Keyboard-visible focus.
- Do not rely on color alone.
- Minimum practical touch target: 44x44px.
- Captions/transcripts for video.
- Heading hierarchy must be semantic.
- Verify all brand/text combinations for contrast before release.

## Responsive breakpoints
- Mobile: <640px
- Tablet: 640–1023px
- Desktop: >=1024px
- Wide: >=1280px

## Core topic-page hierarchy
1. Breadcrumb/category
2. Topic title
3. One-sentence promise/summary
4. Quick answer
5. Key concepts
6. Main explanation
7. Media
8. Sources/citations
9. Optional lesson
10. Optional quiz
11. Related topics
